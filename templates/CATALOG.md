# Template Catalog (HyperFrames, renderer: "hyperframes")

The channel uses **one fixed news frame** for every video, in the style of big
Vietnamese TikTok news pages: the article photo on top, the channel's brand panel
below with the channel pill, the publish date and the **article headline**. The
headline stays the same for the whole video; only the photos change while the
voice tells the story. On-screen text is kept to the headline — **the narration
(`voiceText`) carries the content.**

Fixed parts come from the channel's brand kit (web UI → Cài đặt, or `.env.local`:
`CHANNEL_NAME`, `CHANNEL_HANDLE`, `BRAND_COLOR`, `BRAND_ACCENT`, `BRAND_LOGO`) and
are injected by the pipeline — never put them in `inputs`:

- channel logo + name pill, brand colour panel, "NGÀY ĐĂNG" date tag
- "NGUỒN: <domain>" credit (from `metadata.source.domain`)
- the headline (from `metadata.title`), with `*phrases*` in the accent colour
- a progress bar that runs across the whole video

Both templates render at any length: the clip lasts exactly as long as the
scene's narration and the photo keeps moving (punch-in, then slow Ken Burns).

Images are **project-relative paths** such as `"images/03.jpg"` (the web UI and
the skill download the article's photos into `<outputDir>/images/`).

---

## news-frame

**Role:** hook + every body scene.
**Best for:** all news content — each scene shows the photo(s) that match what
the voice is saying.

| slot            | type     | limit     | notes                                                                                      |
| --------------- | -------- | --------- | ------------------------------------------------------------------------------------------ |
| `image`         | image    | —         | photo for this scene, e.g. `"images/02.jpg"`                                                |
| `images`        | image[]  | ≤3 items  | instead of `image`: 2–3 photos shown as a slideshow within the scene (for longer scenes)    |
| `caption`       | string   | ≤40       | optional small label over the photo (a person's name, a place). Usually leave empty         |
| `headline`      | string   | ≤120      | optional override of the video headline for this scene only. Usually leave empty            |
| `source_credit` | string   | ≤40       | optional override of the "NGUỒN:" credit (e.g. "Trần Tuyển / Báo VietNamNet")               |
| `focus`         | string   | —         | optional CSS object-position to keep a face in frame, e.g. `"50% 20%"`                      |

The first scene (`type: "hook"`) animates the frame in (pill slides, headline
words rise); later scenes keep the frame still so cuts feel continuous.

---

## news-outro

**Role:** outro (always the last scene).
**Best for:** the closing "follow the channel" line — big channel logo with a
pulsing ring and a follow button over a blurred photo.

| slot       | type   | limit | notes                                                                       |
| ---------- | ------ | ----- | --------------------------------------------------------------------------- |
| `image`    | image  | —     | blurred background photo (reuse the hook photo)                              |
| `cta`      | string | ≤24   | button label (default "Theo dõi ngay")                                       |
| `headline` | string | ≤120  | panel text, e.g. `"Theo dõi *AI Coding* để cập nhật tin nóng mỗi ngày"`     |

---

## Editing the templates

Both templates are generated by `scripts/build-news-templates.ts` (shared frame
CSS + runtime). Edit the generator and run `npx tsx scripts/build-news-templates.ts`.
